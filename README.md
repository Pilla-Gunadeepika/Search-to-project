# 🚀 Search-to-Project

### Turn Your Skills into Real-World Projects
Search-to-Project is an AI-powered Streamlit application that helps students discover relevant learning resources and generate personalized, practical project ideas based on their skills, experience level, domain, and interests.

## ✨ Features
* **Personalized project generation:** Generates project ideas based on the student's profile.
* **Web resource discovery:** Uses SerpApi to search for relevant learning materials and project resources.
* **AI-powered recommendations:** Uses OpenAI to generate customized project suggestions.
* **Resource categorization:** Organizes useful search results.
* **Project roadmap:** Provides implementation guidance to help students get started.
* **Skill development:** Explains how a project can help students apply their skills.

## 🛠️ Technologies Used
* Python
* Streamlit
* SerpApi
* OpenAI API
* Requests

## ⚙️ Installation and Setup
1. Install Python on your computer.

2. Clone this repository:

   `git clone https://github.com/Pilla-Gunadeepika/Search-to-project.git`

3. Open the project folder:

   `cd Search-to-project`

4. Install the required packages:

   `pip install -r requirements.txt`

5. Configure your SerpApi and OpenAI API keys securely using Streamlit secrets or environment variables, according to the configuration used in `app.py`.

6. Start the application:

   `streamlit run app.py`
